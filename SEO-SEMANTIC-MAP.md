# Hidden Doors — Semantic Map

Updated: 2026-09-28

This document is the canonical SEO keyword/intention map for the corporate site.
It should be checked before creating or materially rewriting any indexable page.

## Core rule

One page = one primary search intent cluster.

Do not make two indexable pages compete for the same primary intent.
System numbers 36 / 42 / 59 are product architecture. Search landing pages are based on how users formulate needs.

## Rule before adding any new indexable URL

Answer all five:

1. What exact user intent does this page own?
2. Which existing page would otherwise compete with it?
3. Do we have enough unique useful content to justify the URL?
4. What pages link to it, and where does it link onward?
5. What business action should a visitor take on it?

If answers are weak, add the topic as a section to an existing page instead of creating a new indexable page.
