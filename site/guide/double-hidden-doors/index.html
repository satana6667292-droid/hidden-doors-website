01 / КОНФИГУРАЦИЯ

Сначала решите,
как будут работать две створки.

У широкого проёма есть два основных сценария — активная + пассивная створка или две активные створки.

02 / РАЗМЕРЫ СТВОРОК

Ширину задают
для каждой створки отдельно.

Не обязательно делить широкий проём на две одинаковые части — конфигурация зависит от сценария использования.

МИНИМУМ

400 мм

Нижняя граница ширины отдельной створки в текущей конфигурации двустворчатой системы 42 мм.

МАКСИМУМ

1000 мм

Верхняя граница ширины отдельной створки. Конкретный проект проверяется вместе с высотой и комплектацией.

АСИММЕТРИЯ

Створки могут отличаться

Если одна часть используется ежедневно, её ширину можно выбирать отдельно от пассивной створки в пределах допустимого диапазона.

03 / ОТКРЫВАНИЕ

Для двух створок
Reverse не используется.

Двустворчатую дверь 42 мм нельзя проектировать по логике одностворчатого Reverse. Это ограничение нужно учесть до подготовки проёма.

Не переносите параметры одностворчатой двери автоматически

Для одностворчатой 42 мм доступны Classic и Reverse, но для двустворчатой конфигурации Reverse исключается. Сценарий движения каждой створки нужно проверить на плане.

04 / ФУРНИТУРА

Комплект для двух створок
считается отдельно.

Не умножайте автоматически одностворчатый комплект на два — итог зависит от активной/пассивной логики и конкретного проекта.

ПАССИВНАЯ СТВОРКА

Шпингалет — отдельная позиция

Если пассивную створку нужно фиксировать в закрытом положении, шпингалет добавляется отдельно.

ПЕТЛИ / ЗАМОК

Проверяются по спецификации

Количество и набор фурнитуры фиксируются под конкретную двустворчатую конфигурацию, а не выводятся из одностворчатой автоматически.

ДОП. ОПЦИИ

Согласуются до запуска

Стопор, специальные работы и другие механизмы должны быть явно указаны в итоговой комплектации.

05 / ПЛАНИРОВКА

Широкий проём требует
больше свободного пространства.

Две створки нужно проверять одновременно с мебелью, проходами и соседними дверями.

АКТИВНАЯ СТВОРКА

Определите основной маршрут

Ежедневно используемая створка должна открываться в удобную для движения зону.

ПАССИВНАЯ СТВОРКА

Проверьте, зачем она открывается

Например, для заноса крупной мебели или полного раскрытия широкого прохода — сценарий лучше определить заранее.

ДВЕ АКТИВНЫЕ

Проверьте обе траектории

Обе створки должны работать без конфликта с мебелью, электрикой и соседними проёмами.

07 / КОГДА ДВЕ СТВОРКИ ИМЕЮТ СМЫСЛ

Выбирайте по задаче,
а не ради симметрии.

Двустворчатая дверь полезна там, где нужен широкий проход и есть понятный сценарий работы обеих частей.

ШИРОКИЙ ПРОХОД

Полное раскрытие при необходимости

Пассивная створка может подключаться тогда, когда стандартного ежедневного прохода недостаточно.

ДВЕ РАБОЧИЕ СТВОРКИ

Постоянное использование обеих частей

В этом случае особенно важно проверить движение створок и окружение проёма.

ДИЗАЙН

Пропорции стены

Ширины створок лучше выбирать вместе с общей архитектурой стены, а не только по арифметическому делению проёма.

08 / ЧАСТЫЕ ВОПРОСЫ

Коротко о двустворчатых
скрытых дверях.

В какой системе Hidden Doors есть двустворчатая скрытая дверь?

В текущей линейке двустворчатое скрытое исполнение предусмотрено для системы 42 мм.

Какая ширина может быть у каждой створки?

От 400 до 1000 мм для каждой створки.

Обязательно ли делать одну створку пассивной?

Нет. Можно использовать конфигурацию активная + пассивная или сделать обе створки активными.

Есть ли Reverse у двустворчатой двери?

Нет. Для двустворчатого исполнения системы 42 мм Reverse не используется.

Шпингалет входит в базовый комплект?

Нет. Для фиксации пассивной створки шпингалет добавляется как отдельная позиция.
